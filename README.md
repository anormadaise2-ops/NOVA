# NOVA Platform

NOVA is a communication platform with authentication, real-time messaging,
voice messages, WebRTC calls, support tickets, and a shared Tauri desktop
client. It also contains the separate `nova-code-ai/` VS Code extension.

## Local development

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Render free deployment

The [render.yaml](./render.yaml) configures a free Node.js Web Service:

- Build: `npm install`
- Start: `npm start`
- Health check: `/api/status`
- WebSocket: same HTTPS host using `wss://`
- `SESSION_SECRET`: generated by Render

In Render choose **New + → Blueprint**, select
`anormadaise2-ops/NOVA`, and apply the blueprint. Render will provide an URL
such as `https://nova-xxxx.onrender.com`. A custom domain can be added from
**Settings → Custom Domains**.

The free filesystem is not persistent. Move `data/database.json` and
`data/voices/` to PostgreSQL/object storage for production.

## NOVA Code AI

```bash
cd nova-code-ai
npm install
npm run compile
npm run package
code --install-extension nova-code-ai-0.1.0.vsix
```

The extension supports Ollama and OpenAI-compatible providers. API keys are
stored only in VS Code SecretStorage.

## Windows desktop

```bash
npm run tauri:dev
npm run tauri:build
```

Installers are written to `src-tauri/target/release/bundle/`.

## Roles and environment

Set support/admin users with:

```env
NOVA_SUPPORT_USERS=alice:admin,bob:support
```

Never commit real secrets. See [.env.example](./.env.example).

## Structure

- `server.js`: Express, sessions, WebSocket, support and local storage.
- `public/index.html`: shared NOVA web/desktop UI.
- `nova-code-ai/`: TypeScript VS Code extension.
- `src-tauri/`: Tauri Windows wrapper.
